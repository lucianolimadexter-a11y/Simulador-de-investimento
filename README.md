# Radar Cripto · Simulador

PWA que acompanha, em tempo real, as 10 criptomoedas com maior momentum de alta (via CoinGecko) e ações da B3 (via brapi.dev), com carteira virtual de investimento simulado.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub e suba estes 4 arquivos (`index.html`, `manifest.json`, `icon.svg`, `sw.js`) na raiz.
2. No repositório: **Settings → Pages → Source**, selecione a branch (ex: `main`) e a pasta `/ (root)`.
3. Salve. O GitHub gera uma URL do tipo `https://seu-usuario.github.io/nome-do-repo/`.
4. Abra essa URL no celular e use "Adicionar à tela inicial" pra instalar como app (PWA).

## Ações da B3 (opcional)

Sem token, só aparecem 4 ações de teste. Pra liberar as outras:
1. Crie uma conta grátis em [brapi.dev/dashboard](https://brapi.dev/dashboard)
2. Copie o token
3. Abra o app → aba **Ações** → cole o token no campo indicado e salve (fica salvo no navegador)
